Running the Project Locally

Clone the repository:
    git clone https://github.com/Raghav101010/portfolio.git
Move into the project directory:
    d portfolio
Install dependencies:
    npm install
Run development server:
    npm run dev
Open in browser:
    http://localhost:3000
